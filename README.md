# pull.

Download YouTube, Facebook, Instagram, TikTok and Vimeo video in full quality, right from the page you're watching.
Capture any frame at full resolution, pull stills from a whole clip, and convert 2K/4K to H.264 MP4 for editing.

by **LAB. x SUNN.** (Trithaset Chaimongkol)

## Download

| | |
|---|---|
| **Windows 10 / 11** | [pull-setup-win.exe](https://github.com/mutesonix/pull./releases/latest/download/pull-setup-win.exe) |
| **macOS 11+** (Apple Silicon & Intel) | [pull-setup-mac.zip](https://github.com/mutesonix/pull./releases/latest/download/pull-setup-mac.zip) |

Works with Chrome, Brave, Edge and Arc, plus Safari on Mac. pull. updates itself once installed.

**Windows:** if "Windows protected your PC" appears, click **More info → Run anyway** (the installer isn't code-signed yet).
**Mac:** right-click **pull. Setup → Open**. If macOS blocks it: System Settings → Privacy & Security → **Open Anyway**.
